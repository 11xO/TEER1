# teer

تطبيق React.js مكتوب بـ JSX، بنفس التصميم العربي واتجاه RTL، مع دعم التثبيت على الموبايل كتطبيق PWA.

## التشغيل

يتطلب Node.js إصدار 22.13 أو أحدث؛ يُفضّل إصدار 24 لخادم API.

```sh
npm install
npm run dev
```

```sh
npm run build    # بناء نسخة الإنتاج
npm run preview  # تجربة نسخة الإنتاج والتثبيت محليًا
npm run lint     # فحص الكود
npm test         # اختبارات التسعير والخصومات والطلبات
npm run test:e2e # اختبارات المتصفح بعد البناء وتثبيت Chromium
```

لاختبارات المتصفح شغّل `npx playwright install chromium` مرة واحدة، ثم `npm run build` قبل `npm run test:e2e`. الاختبارات تستخدم بيانات معزولة ولا ترسل طلبات إلى Firebase الحقيقي.

## تنظيم المشروع

- [src/features](./src/features): شاشات التسجيل والانتظار والرئيسية والطلبات والشحن والماركت والمكافآت والحساب، بمكونات JSX.
- [src/components](./src/components): النوافذ وعناصر الواجهة المشتركة.
- [src/context/AppContext.jsx](./src/context/AppContext.jsx): حالة التطبيق والتنقل والإجراءات المشتركة.
- [src/hooks](./src/hooks): اشتراكات Firebase وحالة الإنترنت والتثبيت.
- [src/api](./src/api): اتصالات Firebase وREST والتحقق وSchemas والنماذج وTanStack Query والتحديثات المباشرة.
- [api](./api): خادم Node.js للتحقق من واتساب والجلسات وWebSocket؛ [دليل التفعيل والتشغيل](./api/README.md).
- [src/services](./src/services): تخزين جلسة المستخدم وإعدادات العرض محليًا.
- [src/styles/original.css](./src/styles/original.css): تنسيقات التصميم الأصلي.
- [src/styles/app.css](./src/styles/app.css): دعم safe areas والموبايل وإمكانية الوصول.
- [public](./public): الصور الأصلية وأيقونات التطبيق.
- [src/sw.js](./src/sw.js): التخزين المؤقت لواجهة التطبيق والإشعارات.
- [vite.config.js](./vite.config.js): إعدادات البناء وPWA.

## إعداد البيانات

خدمة كود واتساب جاهزة للربط بمفاتيح Twilio Verify، وتظل غير مفعلة افتراضيًا لحين إعدادها. عند تفعيلها، لا يُسمح بالدخول إلا بعد تأكيد كود حقيقي، ثم ينتقل المستخدم مباشرةً إلى التطبيق. راجع [دليل API](./api/README.md) لتشغيل الخادم وتفعيل التحقق.

إعدادات Firebase الحالية محفوظة، مع الاحتفاظ بمسارات البيانات ومفاتيح جلسة المستخدم القديمة. لتغيير المشروعين، انسخ [.env.example](./.env.example) إلى `.env.local` وعدّل القيم ثم أعد تشغيل خادم التطوير. صلاحيات البيانات يحددها Firebase Security Rules؛ عند تعطيل التحقق الحقيقي يستمر تدفق تسجيل الرقم وموافقة الإدارة الموجود في المشروع الأصلي.

## التشغيل كتطبيق

ارفع محتويات [dist](./dist) بعد البناء على استضافة HTTPS. يدعم البناء المسارات الفرعية، والتشغيل بملء نافذة مستقلة، واختصار «طلباتي»، وأيقونات Android وأيقونة الشاشة الرئيسية في iOS. على Android استخدم «تثبيت التطبيق»، وعلى iPhone اختر «إضافة إلى الشاشة الرئيسية» من قائمة المشاركة.

بعد أول زيارة ناجحة تتوفر واجهة التطبيق والصور والخطوط بدون إنترنت؛ تسجيل الدخول والبيانات الحية وإرسال الطلبات واستبدال النقاط تحتاج اتصالًا. لا تُخزّن استجابات Firebase في Service Worker. يُفعّل Service Worker في نسخة الإنتاج، ويمكن اختباره محليًا بأمر المعاينة.

هذا المشروع ينتج PWA قابلة للتثبيت؛ ملف APK أو IPA يحتاج مرحلة تغليف وبناء أصلية منفصلة. دعم استقبال إشعارات push محفوظ، وإرسالها يحتاج خادمًا واشتراك Push كما في أي تطبيق ويب.
